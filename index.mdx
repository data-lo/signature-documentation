title: "Introducción"
description: "Integra el flujo de firma a través de la API de Firmalo."
---

La API de Firmalo permite que tu sistema cree documentos PDF con su flujo de firmas, consulte su estado y gestione el acceso de los firmantes, sin que tus usuarios tengan que entrar a la plataforma para iniciar el proceso.

## Qué puedes hacer

- Crear flujos de firma: envía un PDF, asigna firmantes y agrega testigos de forma automatizada.
- Consultar documentos: filtra y revisa los documentos de tu organización o de uno de sus usuarios.
- Elegir tipos de firma: usa firma simple, avanzada con e.firma o biométrica según el flujo que requieras.
- Consultar la organización: revisa el saldo de documentos, el plan activo y el ciclo de facturación.

## Cómo funciona

<Steps>
  <Step title="Tu backend crea el documento">
    Envía el PDF y los datos de los participantes con la API key de tu organización. Firmalo reserva un crédito de documento y crea el flujo con estado `PENDING_SIGNATURE`.
  </Step>
  <Step title="Firmalo invita a los participantes">
    Cada participante recibe un correo. En un documento secuencial, los firmantes firman uno a la vez.
  </Step>
  <Step title="Tu sistema consulta el resultado">
    Consulta el estado del documento hasta que quede `SIGNED`, `REJECTED` o `CANCELLED`.
  </Step>
</Steps>

<Warning>
  Llama a la API únicamente desde tu backend. Nunca expongas la API key en un navegador, una app móvil o código del cliente.
</Warning>
