En esta guía creas un documento con un firmante y consultas su estado.

## Antes de empezar

Necesitas:

- Una [API key](/authentication) con los permisos `DOCUMENT.CREATE` y `DOCUMENT.READ`, ambos con alcance `ORGANIZATION`.
- Créditos de documento disponibles en tu organización.
- Un PDF de hasta 20 MB.

Guarda el host de la API y tu llave en variables de entorno:

```bash
export FIRMALO_API_URL="https://<host>"
export FIRMALO_API_KEY="<tu-api-key>"
```

Para ver cuántos documentos puedes crear, consulta el contexto de tu organización. El saldo está en `data.signatureQuota.documentsRemaining`.

```bash
curl "$FIRMALO_API_URL/api/v1/integration/organization/context" \
  -H "X-API-Key: $FIRMALO_API_KEY"
```

## Crea el documento

Envía `multipart/form-data` con el PDF en `file` y los datos del documento en `payload`, como texto JSON.

```bash
curl -X POST "$FIRMALO_API_URL/api/v1/integration/documents" \
  -H "X-API-Key: $FIRMALO_API_KEY" \
  -H "Idempotency-Key: erp-contrato-2026-000184" \
  -F "file=@contrato.pdf;type=application/pdf" \
  -F 'payload={
    "creator": { "email": "ana.lopez@cliente.example", "firstName": "Ana", "lastName": "López" },
    "document": { "signatureType": "SIMPLE", "isSequential": true },
    "participants": [
      {
        "role": "SIGNER",
        "firstName": "Luis",
        "lastName": "Martínez",
        "email": "luis.martinez@correo.example",
        "order": 1,
        "signaturePositions": [
          { "page": 1, "xRatio": 0.1, "yRatio": 0.8, "widthRatio": 0.25, "heightRatio": 0.08 }
        ]
      }
    ]
  }'
```

- `Idempotency-Key`: usa una clave nueva por documento, como el folio de tu sistema. Con ella puedes reintentar sin duplicar; consulta [Idempotencia](/idempotency).
- `creator`: quien crea el documento, identificado por su correo. Si no tiene cuenta, se le crea una provisional.
- `order`: el turno de cada firmante en un documento secuencial, desde `1`.
- `signaturePositions`: dónde va la firma. `xRatio` y `yRatio` se miden desde la esquina superior izquierda de la página, como fracción de su ancho y su alto.

La respuesta es `201`. Guarda `data.id` para consultar el documento:

```json
{
  "success": true,
  "message": "Documento y flujo de firmas creados correctamente",
  "data": {
    "id": "2be3b9d7-4c5d-4e6f-8a9b-0c1d2e3f4a5b",
    "status": "PENDING_SIGNATURE",
    "signatureType": "SIMPLE",
    "fileName": "contrato.pdf",
    "createdAt": "2026-10-26T12:00:00.000Z",
    "creator": { "email": "ana.lopez@cliente.example" },
    "participantsCount": 1,
    "publicUrl": "https://app.firmalo.com/public/documents/2be3b9d7-4c5d-4e6f-8a9b-0c1d2e3f4a5b",
    "participants": [
      {
        "email": "luis.martinez@correo.example",
        "status": "PENDING",
        "signatureType": "SIMPLE",
        "order": 1,
        "taxId": null
      }
    ]
  }
}
```

## Consulta el estado

Lista los documentos firmados de tu organización:

```bash
curl "$FIRMALO_API_URL/api/v1/integration/documents?statuses=SIGNED&limit=25" \
  -H "X-API-Key: $FIRMALO_API_KEY"
```
